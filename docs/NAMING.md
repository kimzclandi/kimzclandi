# 项目名称与兼容性

项目展示名称：**kimzclandi｜数据工程与模型实验**。

GitHub 仓库名：`kimzclandi`。

此仓库与账号同名，用于展示个人主页，保留 `kimzclandi`。

## 获取代码

```sh
git clone https://github.com/kimzclandi/kimzclandi.git
cd kimzclandi
```

已有 checkout 可在仓库根目录更新 remote；本地目录是否改名不影响运行。

```sh
git remote set-url origin https://github.com/kimzclandi/kimzclandi.git
```
