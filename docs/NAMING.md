# 项目名称与兼容性 / Naming and compatibility

个人主页显示名为 **kimzclandi｜模型推理、压缩与数据工程**。账号同名仓库 `kimzclandi` 继续承担个人主页导航。

## 名称约定

- 中文显示名说明任务，英文 README 使用可读标题；仓库 slug 使用下表已建立的规范名称。
- 新链接、clone 命令与徽标使用规范 URL。显示名调整不产生新项目或新实验成果。
- 不为统一大小写反复改 URL；Python 包名、import、CLI、协议字段与固定结果标识保持兼容。
- 冻结协议、源码快照、manifest、原始记录、历史报告及许可条款不作全局替换；旧名称是同一项目的历史标识。

Display titles describe the task; repository slugs remain stable. Use canonical URLs for maintained entry points. Historical aliases in frozen evidence and package identifiers remain unchanged.
