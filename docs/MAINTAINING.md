# 维护个人主页项目目录

本仓库与 GitHub 用户名同名；公开仓库根目录的 README.md 会显示在个人主页。

## 添加新项目

1. 在独立仓库中完成项目，并确认公开链接、启动说明与结果证据可用。
2. 在 README.md 对应分类下加入项目名称、仓库链接、一句话问题描述、实际产物、技术栈和验证边界。
3. 加入该分类的第一个项目时，删除“暂无公开项目”的说明。
4. 跨方向项目选择一个主分类，其他位置用链接引用，避免重复描述。
5. 提交 README.md 的更新；不需要移动原项目、复制源码或更改其远程地址。

## 项目条目应该回答

- 解决什么具体问题？
- 哪些功能和实验实际运行过？
- 从哪里启动、检查代码和查看证据？
- 结果依赖哪些假设，有什么尚未验证的内容？

使用公开 GitHub 链接，不加入本机绝对路径、私人资料或密钥。计划中的项目应明确写为计划，不计入已完成成果。
